# 🎓 SRM Attendance Calculator M.Tech 2028

A lightweight desktop application built with **Python**, **CustomTkinter**, and **Pandas** to help SRM PG students manage their attendance according to the 75% attendance requirement.

## ✨ Features

- 📅 Calculate total classes for each subject based on the academic timetable.
- ✅ Find the minimum number of classes required to maintain **75% attendance**.
- 📊 Display total classes and overall attendance requirement for the selected month.
- 🌐 Automatically downloads the latest timetable from GitHub.
- 🧳 Attendance Predictor (Work in Progress) to estimate attendance after skipping classes for trips or holidays.
- 🖥️ Standalone Windows application.

## 🛠️ Built With

- Python 3
- CustomTkinter
- Pandas
- PyInstaller

## 📂 Timetable

The application reads the academic timetable from a remotely hosted CSV file, allowing updates without redistributing the application.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/srm-attendance-calculator.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

Or use the standalone Windows executable.

## 📌 Requirements

- Windows
- Internet connection (required to download the latest timetable)
